# ProN Google Apps Script

Este `Code.gs` es el backend de ProN para GitHub Pages y Google Sheets.

## Instalacion

1. Abre el proyecto de Apps Script que publica este endpoint:
   `https://script.google.com/macros/s/AKfycbzf1TjxIBrBNJ6fTY5NNciAlWCl0PFKYgCpRXcdRg2S9aYKjMqDxeVCgC1JlcZet8iLNA/exec`
2. Pega el contenido de `Code.gs`.
3. Ejecuta `setupProN` una vez para crear las pestanas en la hoja.
4. Publica como Web App: ejecutar como propietario y acceso para cualquier usuario con el enlace.
5. Vuelve a abrir `https://appiba.github.io/ProN/`.

La hoja configurada es:
`https://docs.google.com/spreadsheets/d/1KCzz2B59PN3IvcyM2_G2uvTi8nA759oV7rUsaXvrcSY/edit?gid=0#gid=0`

El correo y la clave del superadministrador no se muestran en la web.
